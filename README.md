# BAB 3 - Peran Pahlawan 🇮🇩

Game edukasi interaktif tentang peran pahlawan nasional Indonesia. Pemain mencocokkan kartu pahlawan dengan asal dan peran mereka masing-masing.

## 🎮 Fitur

- **Drag & Drop** kartu pahlawan ke posisi yang benar
- **Background Music** dan **Voice Over** naratif
- **Sistem Skor** untuk melacak progres pemain
- **Responsif** - dapat dimainkan di desktop maupun mobile

## 🏗️ Teknologi

- HTML5
- CSS3 (vanilla)
- JavaScript (vanilla)
- Google Fonts (Nunito)

## 🚀 Deploy

### Vercel (Recommended)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yusronaja22/bab3-peran-pahlawan)

1. Fork/clone repository ini
2. Import ke [Vercel](https://vercel.com)
3. Tidak perlu konfigurasi tambahan — otomatis terdeteksi sebagai static site
4. Deploy!

### Lokal

Cukup buka `index.html` di browser, atau gunakan live server:

```bash
# Menggunakan Python
python -m http.server 8000

# Menggunakan Node.js
npx serve .
```
